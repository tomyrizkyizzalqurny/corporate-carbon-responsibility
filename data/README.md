# Public demonstration data

The empirical LSEG/Refinitiv firm-level observations are **not** distributed in this repository.

The deterministic file `PUBLIC_REPLICATION_SYNTHETIC_V26.csv` is part of the archived reproducibility package at Zenodo DOI `10.5281/zenodo.22764482`. It contains synthetic identifiers only and is intended to demonstrate the computational workflow; it cannot reproduce the numerical estimates reported in the article.

To run `code/python/PUBLIC_REPLICATION_PYTHON_V28.py`, place the archived `PUBLIC_REPLICATION_SYNTHETIC_V26.csv` in this directory.

Do not place licensed LSEG/Refinitiv exports or reconstructed firm-level data in this directory or commit them to GitHub.
