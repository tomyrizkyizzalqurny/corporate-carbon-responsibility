# Extended Data

The publication-facing Extended Data workbook is archived permanently with the reproducibility package on Zenodo:

**DOI:** `10.5281/zenodo.22764482`

The archived workbook `KBK_2023_A++_EXTENDED_DATA_SUBMISSION_FINAL.xlsx` contains secondary analyses, robustness checks, diagnostics, configuration-threshold sensitivity, and verified final Q1 bootstrap evidence. The Extended Data package does not redistribute licensed LSEG/Refinitiv row-level observations.

The repository's `documentation/EXTENDED_DATA_MASTER_ARCHITECTURE_V24.txt` documents how the Extended Data modules map to the frozen analytical evidence trail.
