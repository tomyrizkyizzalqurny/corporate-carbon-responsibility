# Data access and licensing boundary

The empirical analysis is based on LSEG/Refinitiv firm-level source data obtained under an institutional subscription. Those licensed raw and reconstructed row-level observations are not included in this public repository.

Researchers seeking numerical reproduction must obtain authorized access to equivalent LSEG/Refinitiv source fields and use the public field map, reconstruction helper, and analytical source code.

The deterministic synthetic dataset, when mirrored in this repository, contains no real firm identifiers and is provided only to demonstrate the computational workflow. It must not be interpreted as a substitute for the licensed empirical dataset or as an independent numerical validation of article estimates.
